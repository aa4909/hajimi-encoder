# Hajimi Encoder

这是一个用于加密网页内容的工具，基于纯 HTML 与 JavaScript 构建，可直接部署在 GitHub Pages 上进行在线使用。

## 功能 Features

- 将信息加密混淆
- 支持多种编码方式
- 无需服务器，纯前端运行
